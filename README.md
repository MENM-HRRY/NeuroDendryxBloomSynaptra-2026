# Reagent banks: Buscador Inteligente de Reactivos bilingüe

[![Ir a la App](https://img.shields.io/badge/🚀_Abrir_Aplicación-Visitar-blueviolet?style=for-the-badge)](https://maxenocmn.github.io/Reagen_Banks/)

## 🌟 Propósito del Proyecto
**Reagent banks** nació con la misión de simplificar el estudio y la gestión de conocimientos técnicos complejos. En un mundo saturado de información, esta herramienta permite a los humanos transformar archivos de texto planos en una base de datos interactiva, bilingüe y ultra rápida.

### ¿Por qué es útil?
*   **Optimización del Tiempo:** Encuentra respuestas en milisegundos gracias a su motor de búsqueda con normalización de texto.
*   **Aprendizaje Bilingüe:** Facilita el estudio en inglés y español simultáneamente, ideal para certificaciones internacionales.
*   **Privacidad y Control:** No necesitas subir tus datos a una nube externa; tú cargas tus propios archivos `.txt` y la app los procesa localmente en tu navegador.

---

## 🛠️ Cómo usar Reagent Banks

1.  **Carga tus archivos:** Haz clic en el botón de "Cargar".
2.  **Selecciona tus fuentes:** Puedes cargar un archivo en inglés (obligatorio) y uno en español (opcional) y viceversa.
3.  **Busca:** Escribe cualquier palabra clave en la barra superior. No te preocupes por las tildes, el buscador las ignora para tu comodidad.
4.  **Estudia:** Haz clic en cualquier reactivo para ver su respuesta y explicación detallada si la requieres.

### ⌨️ Atajos de Teclado (Shortcuts)
Para una experiencia de "Power User", puedes controlar la app sin tocar el mouse:

| Acción | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Enfocar Buscador de conceptos** | `Ctrl` + `P` | `Cmd` + `P` |
| **Cambiar Idioma** | `Ctrl` + `S`  o  `Ctrl` + `E` |`Cmd` + `E` o `Cmd` + `S`|
| **Limpiar Búsqueda** | `Ctrl` + `L` | `Cmd` + `L` |
